# BPC v0.11: additive evidence field development result

## Result

**NOT ADOPTED as a capability advance.** v0.11 replaced explicit probability
multiplication with one additive log-evidence query over the two anonymous v0.10
factors. Across three development seeds at 32 steps, it completed 4,870 trials
versus 4,868 for the explicit product: one win and two ties. The two-action
difference is not meaningful evidence of a new capability.

The code and raw development artifacts are retained because the architecture is
useful: it removes an explicit product-policy wrapper while preserving the same
learned relational evidence. v0.12 subsequently tests that architecture with a
third independently discovered factor and new causal deletion controls.

This was development-only. It was not frozen, released, or presented as a
generalization breakthrough.
