# BPC v0.46 rotation-orbit boundary preregistration

v0.45 failed only its new per-orientation frozen gate. v0.46 does not change
the model, capacity, hashes, readout or thresholds. It changes only the source
of physical experience: every independently generated layout is executed in
all four real rotations, so the four anonymous closing actions receive matched
physical contexts rather than independently sampled decorations.

- core hashes remain those frozen by v0.45;
- training seed `461010`: 150 independent layout orbits = 600 worlds and 2,400
  reset transitions;
- holdout seed `461110`: 128 fresh orbits = 512 worlds;
- all worlds exclude every v0.45 pilot, development and frozen world;
- each orbit must contain each closing action exactly once;
- all eleven v0.45 frozen gates remain unchanged, including at least 60%
  strict selection for every orientation;
- the complete unit suite passes before the first run.

This is a development test of symmetry-balanced physical experience, not a
lowered threshold or a frozen success. A pass would authorize one new
independent reproduction. The scope remains one-step closure only.
