## Audit of the existing line

The v0.33–v0.40 factor, field, transition, event-boundary and recursive-belief
models remain reproducible Level-2 mechanism experiments. They are no longer
treated as candidates for the pure core: their factors and separately named
memories are researcher-designed cognitive structure.

## Minimal interface

The new line exposes only a fixed anonymous camera byte array `X`, one of four
anonymous physical action channels `A`, the real next camera array `X'`, and one
bit `E` occupying an ordinary cell in the same array. The model is not given
cell roles, object names, goal coordinates, success paths, distances, factors,
events, memories, scores, rewards, planners, repairs, or search results.

Every output bit uses the same four local physical stencils and writes its real
zero/one residual to the same fixed-capacity Beta medium. Translation reuse and
hash interference are consequences of this medium, not separate functions.
The first experiment tests world prediction only. Goal-directed behavior is not
eligible for development until the world-prediction graduation gates pass.

The external generator may use world objects to create reality, and an external
BFS may reject unsolvable evaluation maps. Neither representation, path nor
distance is exposed to the model.

## What is borrowed from Jev

Jev's proprietary architecture is not public. The transferable evidence is its
interface discipline: one shared state, closed alternatives measured in
parallel, probability distributions returned directly without autoregressive
text, explicit calibration evaluation, and versioned reproducibility. The pure
BPC line adopts those measurement properties for four anonymous physical
actions. It does not import Jev, a language model, an encoder, a decision head,
RLCD rewards, semantic questions, or program-written workflow decomposition.
