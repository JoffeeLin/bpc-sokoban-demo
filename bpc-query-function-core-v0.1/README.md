# BPC Query-Function Core v0.1

Date: 2026-10-04

This directory integrates the current BPC theory and the latest query/residual engineering line into one frozen research baseline.

## One-sentence definition

**BPC is a self-organizing computation medium in which functions are accumulated from real voxel history, participate directly in query-wave evolution, receive Reality Residual only through their actual participation traces, grow finer support when coarse functions repeatedly fail, and can re-enter later queries as ordinary relation state.**

## The current closed loop

\`\`\`text
Raw Reality / Action
        ↓
Query Wave Q
        ↓
Accumulated Voxel Functions participate continuously
        ↓
Prediction Ŷ
        ↓
Real Future Y
        ↓
Reality Residual D = Y - Ŷ
        ↓
Participation-trace reflection
        ↓
Function reshaping / support growth / death
        ↓
Relation state re-enters the next query
        ↺
\`\`\`

The core must not contain task semantic labels, task routers, planners, prewritten Function objects, top-1 path selection, or task-specific exception rules.

## Current strongest evidence

1. **Consequence-grounded lifecycle (v0.3d)**: a new conditional function can become useful without a hand-written maturity threshold; when reality returns to the old rule, the relation dies while accuracy stays 100%.
2. **Dynamic support topology (v0.4d)**: support topology can grow from zero through the same local rule rather than a predeclared pair/triple/quad table.
3. **Causal support focusing (v0.5d)**: six simultaneous raw traces and nested 2→6-order hidden conditions are solved in 16/16 random worlds with \`K = 1→2→3→4→5→0\`, rather than combinatorial support explosion.
4. **Generic query coordinates (v0.6)**: the same frozen support/residual mechanism expresses conjunction, order-sensitive rules, a visible cycle and a reversible ring without adding \`sequence()\`, \`cycle()\` or \`ring()\` operators.
5. **Information-closure boundary (v0.7)**: hidden three-step order and hidden three-phase cycle fail when the query lacks sufficient process state.
6. **Relation-state re-entry (v0.8)**: an accumulated anonymous order-2 function node can re-enter the next query and enable hidden three-step order at 100%; carrier-off and carrier trace-writeback-off both collapse to about 75%.

## Current boundary

The current line does **not** yet prove a fully pure self-generated relation algebra. Remaining scaffolds include fixed raw token identities, hand-specified bottom-level propagation/normalization constants, generic one-step previous-raw/previous-reality carriers, and a separate temporal relation pool in v0.8. Hidden periodic process dynamics remain unresolved.
