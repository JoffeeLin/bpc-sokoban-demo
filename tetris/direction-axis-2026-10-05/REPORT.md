# 继续删除 BPC 俄罗斯方块手脚架：固定方向与竖直地址传播

日期：2026-10-05。基线：提交 `8b094311c5cbabca4aea9ff9ae613574cd21077d`，上一轮局部关系候选的 369 条概率场。

**这两处可以继续删除，且本轮已在 C 沙盒通过冻结检查。** 本实验没有重新从零学习全部游戏；继承旧场，只增加四个空间作用条目，隔离方向与地址轴删除的影响。结果不能证明已经实现完整 Pure BPC。

## 1. 删除了什么

旧闭合传播直接执行 `oy = sy + round(shift)`，只在同一列查找闭合种子，并用 `sy < cy / sy == cy / sy > cy` 分三类。因此“移动方向向下”和“地址沿竖直轴比较”来自代码。

新实现中：

- 四个一跳格点向量的参与幅度从同一个概率场读取。所有正支持相加，归一化成空间作用波；不排序、不挑最大值，没有默认向下的后备规则。
- 源位置到种子位置的差向量，在该作用波上的投影决定地址次序；垂直于波的投影决定是否同一直线。原来的固定竖直函数与同列扫描已经删去。
- 输出位移同时计算横、纵坐标，方向来自波，参与概率与位移长度保持分离。
- 四个概率尚未形成证据时，空间作用为零，不执行这类闭合变化。

预设的一跳尺度、三种次序状态、死亡/出生效果以及旧闭合边界机制仍在。这里删除的是固定方向和固定轴，不是宣布这些结构也已自生。

本轮编译的 `model.c` 不含旧玩家的 `lp_choose / lp_score`，也不含旧课程中的像素距离排序信用。当前核心约 16 KB；其中一部分体积减少只是删除旧辅助代码，不能把体积缩小当作纯净度证明。

## 2. 方向数值如何学到

使用 17 条手写匿名操作序列。选择序列只依赖随机流，不读取当前棋盘。真实游戏仍决定每次操作的真实后果。为观察一步变化，学习时把最后的落地通道展开成连续的一步脉冲；没有拼接人工训练棋盘。

已有概率场先提出操作后的中间状态。若其持久画面与真实后果不同，四个物理向量分别进入**同一个传播器**，各自形成后果预测。所有向量都统计该预测是否与实际观测完全一致，积累 Bernoulli 条件概率：

`P = (一致次数 + 1) / (观察次数 + 2)`。

这里只记录实际后果的概率，没有误差大小排序、游戏得分、动作优劣评分或人工“向下才正确”的标签。运行时对所有正支持进行波合成，没有重新选候选赢家。

| 显示方式 | 真实游戏块数 / 一步观测 | 有信息变化 | 上 / 左 / 右 / 下的后果概率 | 形成的波 |
|---|---:|---:|---|---|
| 正常 | 20,000 / 297,209 | 28 | 1/30；1/30；1/30；29/30 | (0, +1) |
| 垂直翻转 | 20,000 / 297,252 | 19 | 20/21；1/21；1/21；1/21 | (0, −1) |

翻转由外部观察器对真实游戏画面进行显示变换。核心未接收“正确方向”或翻转标志，只接收变换后的像素。两个场各有 373 条，原来的 369 条学习单元均逐字节不变。

这说明方向数值取决于观测，不能证明“方向关系类型”本身完全自生。四个一跳物理自由度与观察过程仍由程序提供。当前资料一致支持一个方向；冲突、多峰或同时多方向作用没有在本轮毕业。

## 3. 最终冻结验证

方向学习结束后冻结全部场。新世界索引 20–23、操作流种子 20261025–20261029 在正式运行前保留。旧八组作为回归；这是开发者冻结验证，不是独立盲测。

|---|---:|---|
| 原八组世界：8,000 局，每局上限 120 步 | 312,839 / 312,839 | `original_worlds.txt` |
| 新四组世界：4,000 局，同一上限 | 155,379 / 155,379 | `reserved_worlds.txt` |
| 连续预测合计 | **468,218 / 468,218** | 上两项 |

| 翻转显示的闭合组件，任意位置 1–4 行 | 10,000 / 10,000 | `reflected_closure.txt` |

连续预测每步使用模型自己上一步的画面和 trace，不覆盖真实下一棋盘。只允许每局初始可见输入，以及真实成功落地之后的新外源 Preview；所有完整画面、事件和诊断 trace 均核对。概率场在评估前后逐字节相同。

无评分操作流不是能打高分的玩家：50,000 块发生 36 次单行消除和 2,634 次 GameOver；均被正确预测，没有实际四行消除。四行能力在专门的多行验证中检查。这里不能把块数或操作数解释成玩法水平。

专门棋盘只用于验证，未进入方向训练。以上计数没有去重，也不能直接作为总未见泛化数量 G。翻转结果只验证闭合传播组件，没有验证整个翻转游戏的几何、Preview 接口或第二种任务；没有声称整个模型支持任意镜头变换。

| 四个方向证据清零 | 0 / 400 |
| 方向证据反转 | 0 / 400 |
| 方向证据转九十度 | 0 / 400 |

每个干预只改变四个方向条目的概率统计，随后恢复原场，其他条目不变。另有全场清零、操作错位、trace 清零对照，均造成预测退化，原始数值在 `controls.txt`。

一个重要负例是：新传播器直接加载旧场、完全不学习方向时，短随机流仍 **8,083 / 8,083** 通过；同场消行用例却 **0 / 400**。因此“删除后随机流还预测正确”不足以证明能力保持。这也是本轮保留专门事件检查和负日志的原因。

旧非连续三行消除修复继续保留；本轮没有针对该反例写新分支。任意位置多行用例检验保留行跨多个闭合地址的传播。

## 5. 工程证据与复现

严格 C11、`-Wall -Wextra -Werror -pedantic` 编译通过。O2/O3 在同一场上执行 23,762 步、2,000 个消行和 500 个不消行，用输出仅去掉 CPU 时间后逐字节比较，一致。UBSan 检查通过，标准错误零字节。

推理根函数的源码可达性检查未到达真实游戏、信用写入或训练中间态函数；新目录的源码没有玩家启发式评分和像素距离排序。该检查不是形式化证明，运行时冻结和结果自回馈提供补充证据。

正常场审计值 `eabafd53cdb66fc0`，SHA-256 `2f6e0731eed408c3048d1d256ec3bc3cf404c6f48efe29310cba85ef19becf87`。翻转场审计值 `ca3829a5062b4697`。各原生 C 快照均为 18,440 字节，包含固定容量及查找索引；不是最小条目序列化格式。

`sh reproduce.sh` 从上一版冻结场重新学习四个概率，运行正式正负对照。快照采用原 Linux C ABI；跨 ABI 需先在新环境重建上一版初始场。

## 6. 剩余的主要手脚架

1. 活动/持久分组、trace 的角色、Preview 区域、GameOver 位置仍手工解释；训练观察器仍读取仿真器 `State` 的这些分组。
2. route/life/spawn/closure 的串接及原有分阶段知识仍在。旧 369 条来源于上一版学习；本轮并未重新证明全部历史训练过程符合当前限制。
3. `PT_ROUTE / PT_FEAS / PT_DESTSTATE / PT_ADDRREL / PT_EFFECT` 等类型和三个次序状态仍预设。一跳尺度、局部关系解析、地址锚点仍存在。
4. 新方向条目在既有空间效果参与时读取，没有证明效果角色、上下文分化和关系生成机制能够自行出现。

因此本轮结论限于：**固定向下与固定竖直地址传播可以撤掉，由同一场中新增的四个实际后果概率接替，且本轮验证能力保持。** 下一项更关键的删除对象是活动/持久身份与路由模板；不应通过给它们改名而宣称已经纯净。
