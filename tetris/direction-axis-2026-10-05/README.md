# BPC Tetris：删除固定方向与竖直地址传播

本轮在上一版冻结场上，只学习 **4 个新的空间作用概率**，删除闭合传播里的固定 `+y` 位移和只扫描同列地址的实现。方向与地址次序改为从同一概率场读取的波来决定。

正常显示学到向下；垂直翻转显示学到向上。两次学习中，原 369 个条目逐字节不变。正式场共 373 个条目。**这是增量删除验证，仍不是最终 Pure BPC。**

| 冻结检查 | 结果 |
|---|---:|
| 原八组与新四组连续预测 | 468,218 / 468,218 |
| 连续底部 / 任意位置消行 | 各 10,000 / 10,000 |
| 满竖列不消行 | 2,500 / 2,500 |
| 无评分操作流，50,000 块 | 244,017 / 244,017 次操作 |
| 翻转显示下的闭合组件 | 10,000 / 10,000 |
| 方向清零、反转、转向 | 各 0 / 400；正常 400 / 400 |

新经验来自手写匿名操作序列在真实游戏中的执行。序列选择不读取棋盘，没有玩家评分、搜索、距离比较或正确方向标签。四个物理作用全部获得实际后果的概率统计，没有选出一个候选赢家。
