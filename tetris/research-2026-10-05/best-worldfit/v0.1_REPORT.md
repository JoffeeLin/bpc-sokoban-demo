- v2.1 supplies the fully observable `Visible Active + Visible World + Visible Preview + Action -> next visible state` world and the strongest 8-seed long-rollout reproduction.

## Change in this round

Deleted the dedicated learned LineClear propagation structure from v2.1:

- removed `Prop`;
- removed `train_prop()`;
- removed `prop_step()`;
- LineClear retains only the row participation carrier;
- after a row closure, all rows above are propagated with the same learned one-step Down function already used by normal game motion.

Thus the mechanism becomes:

```text
row closure carrier
-> existing learned Down function
-> repeated world relaxation
```

instead of:

```text
row closure carrier
-> separately trained row Prop function
```
