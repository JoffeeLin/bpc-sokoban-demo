# BPC Best World-Fit v0.6–v0.17 — Purity Deletion Report

Date: 2026-10-05

## Stable capability invariant
Every promoted version preserves the fully observable 10x20 world-fit regression: Left/Right/Down/Rotate/Drop exact, LineClear 1–4 rows 10,000/10,000, arbitrary connected 4/8/12-cell rotation stress exact where enabled, and the eight-seed long rollout with no divergence.

## v0.6 — remove explicit row grouping
LineClear no longer receives a row identity. A candidate closure wave is born when an occupied one-hop relation physically connects one boundary to the opposite boundary. Reality residual matures horizontal closure and suppresses vertical closure. Vertical-through-board non-clear control: 2500/2500.

## v0.7 — relation rotation instead of pattern memory
Deleted the 1M-slot 7x7 rotation pattern memory and the seven-Tetromino training catalogue. Rotation is reconstructed from a reality-born gauge, two minimal relation bases and binary phases learned from 1/2/3-cell micro reality. Random connected 4/8/12-cell shapes: all 5000/5000 exact.

## v0.8 — sparse reality-born Spawn + split reuse
Deleted the Preview-to-Active 16x200 table. Raw single-cell before/after Spawn experience yields one reusable displacement relation `(3,-1)`. Spawn reuses the same direct/complement split family rather than a separate Spawn-specific function.

## v0.9 — learned action lifetime
Deleted the explicit HardDrop loop. Every action has a learned Action->Action lifetime relation. The field learns that the Drop carrier persists while feasible and dies on lock; other actions are one-shot.

## v0.10 — raw micro-experience only
Move and Spawn learners no longer compute their target coordinates internally. External micro-reality produces before/after states; the learner only extracts residual relations. Strict compiler/O2-O3/UBSan audit passed.

## v0.11 — one geometry relation field
Move, Rotate and Drop no longer have different geometry learners. One `Geom` field learns gauge + basis + phase for all anonymous action carriers. Rotation becomes the same relation machinery with basis swap and phase.

## v0.12 — raw consequence routing
Deleted handwritten `side/rotate blocked -> stay` and `down/drop blocked -> lock`. Raw before/after micro reality learns candidate->Active, persistence->Active and Active->World routes.

## v0.13 — no fixed closure directions
Deleted the predeclared +/-x,+/-y closure vocabulary. Candidate directions may exist only when the current visible state actually contains that one-hop relation. Reality matures horizontal closure and suppresses vertical closure.

## v0.14 — diagnostic: residual-reduction credit too broad
Removed hardcoded Down reuse for LineClear, but credited every action effect that merely reduced global Hamming residual. Full world stayed exact, yet all actions received high horizontal-closure child credit. This is NOT accepted as a purity success; it exposed non-specific causal credit.

## v0.15 — exact reality credit
Each candidate child effect is independently credited only when its consequence exactly matches the real closure consequence. No top-1. Only the two effect-equivalent downward actions mature; Left/Right/Rotate remain low. Full capability stays exact.

## v0.16 — effect-equivalence compression
Closure no longer couples to Action IDs. It couples to anonymous spatial-effect relations. Down and Drop collapse to one effect class `(0,+1)`, which alone matures for horizontal closure. This is a stronger function-reuse result: higher-order functions cite an effect, not an operation name.

## v0.17 — raw Spawn/GameOver split
Deleted the hand-taught blocked/unblocked split truth table. The direct/complement Spawn-vs-GameOver split is learned only from raw Preview+World -> real Spawn consequence. It converges to direct=1 when feasible and complement=1 when blocked.

## Current compressed interpretation
`raw visible state + anonymous action carrier -> reality-born geometry/effect relations -> raw channel consequence routes -> recurrent action lifetime -> boundary closure -> effect-equivalence coupling -> sparse cross-region Spawn relation -> fixed-point world dynamics`

## Remaining high-value scaffolds
1. Multiple parameter/operator families still exist instead of one shared field.
2. Active/World/Preview are still named structures in this Best World-Fit implementation, although the independent v0.180 audit proved their fixed semantic names are unnecessary.
3. Training is still split into micro-curricula rather than one continuous residual-driven reality stream.
4. Several learners still have family-specific observers even when their contents are reality-born.
5. Address/coordinate topology is supplied as physical substrate.
