# BPC 俄罗斯方块：继续删除手脚架的实验结果

日期：2026-10-05。基线：`JoffeeLin/bpc-sokoban-demo`，提交 `7025e147cd0aaf8423d6d5f7f4d1889f5765e08a` 的 v0.40b。

本轮删除了全局几何基底/相位解析与变换候选胜者、人工微形状几何课程、Lock 触发的推理下游调度，以及人工 Spawn 棋盘课程。联合候选保留了本实验世界的拟合能力，并修复了旧基线未覆盖的非连续消行反例。**目前只能称为进一步纯净化的世界拟合候选，不能宣布已经实现完全纯净 BPC。**

## 1. 实际删除与替换

| 旧结构 | 本轮实现 | 仍存在的边界 |
|---|---|---|
| 从整个活动形状抽取 basis/phase，再重建变换 | 真实游戏中局部邻接方向对的共现概率；所有正支持同时参与；位置同步松弛 | 四个一跳方向、局部关系对解析及最小地址锚点仍为物理观察器提供 |
| 人工 1/2/3 格微形状训练几何 | 180,000 次实际执行的游戏操作；133,912 次直接变化和 37,698 次宏变化接受信用 | 宏位移被观察器压成单位方向，仍是预设机制 |
| Lock 判定后才调用下游求解器 | 每个推理微步都调用下游，事件载流幅度混合前后状态；训练辅助微步也持续调用 | Spawn/closure 与 route/life 的串接关系仍手工安排 |
| 随机拼 Preview 与障碍棋盘，训练 Spawn/GameOver 初值 | 2,500 次真实 Down/Lock 观测建立初值；随后仍从可见游戏过程重学最终证据 | 阶段顺序、角色解释和信用观察器尚未自生 |
| 预测、效果反事实、关系对反事实各有一套闭合执行代码 | 共用 `sf_transport`，干预只修改一个概率幅度 | 空间效果和地址关系候选仍预设 |

这些变化没有新增旋转公式、方块类型判断、特定“三行”修补或 inference 内的真实环境调用。旧完整几何变换的候选赢家已删；空间关系词表并未全部自生。

局部几何统计放在同一个 `SharedField`：给定操作与输入中出现的无序邻接方向对，统计输出中各个方向对是否出现，使用 Beta(1,1) 条件概率。运行时汇合有正支持的关系，归一化局部方向，在实际邻接图上同步松弛坐标，最后测量目标像素。没有逐点实例对应标签、七类方块标签或游戏得分进入这个几何信用。

字段由基线 219 个概率条目增至 369 个，增加 150 个。删除手脚架不是“参数也变少”的结论。新增通用地址哈希索引只缓存条目位置，没有增加学习值；对旧联合候选曾验证优化前后学习单元字节相同。

## 2. 发现并保留的反例

第一次联合候选在外部玩家种子 `20261010` 的第 253 块（零基索引 252）、操作通道 4 / HardDrop 上失败：`1140/1141`。重新运行旧 v0.40b 和只删除几何的候选，均在同一位置失败，活动 trace 与 Lock 正确，持久棋盘错误。

该步同时消去三个**不连续**的满行。中间保留行本应移动两格；旧传播器把关系对概率 `0.75` 乘进位移，得到约 `1.48`，取整只移动一格。它拼出一个虚假满行，下一次松弛又多消了一行。

改动是把位移和条件概率幅度分开：概率表示一个空间事件参与的强度，不缩短该事件的位移；同一地址的相关提案按最大幅度合并，避免重复提案堆出确定性。预测与反事实信用使用相同执行器。最大幅度合并在这里只经过本游戏验证，不能据此证明它是所有世界的通用规律。

关键对照：**不重新训练**，当前执行器加载失败版本的同一份 `negative_field.bin`，种子 `20261010`–`20261014` 的五条轨迹全部通过。修复因此不依赖把反例加入训练。随后正式候选重新训练，使学习和执行机制一致。

原始失败、旧基线失败及同场修复日志全部在 `evidence/`。`reproduce_negative.sh` 可直接复现负例和修复。

删除人工 Spawn 初始课程之后，再次从零训练冻结。世界索引 16–19 与外部玩家种子 20261020–20261024 在本次运行前预留。此前已看过的世界索引 8–15、玩家种子 20261010–20261019 都归为开发/回归数据，不再称为未见验证。

| 新保留四组世界，4,000 局，上限 120 步 | 155,842 / 155,842；trace 全一致 | `reserved_worlds.txt` |
| 两组世界合计 | **468,681 / 468,681** | 上两项 |

外部玩家新轨迹出现 13 次真实 GameOver，模型也预测一致。这些计数是拟合准确率；外部玩家的成绩不能算成 BPC 的自主玩法能力。

每个下一步输入使用**模型自己上一步的棋盘和 trace**，不把真实下一帧替换进去。每局初始屏幕是外部输入；真实成功 Lock 后只注入新随机 Preview 像素，作为新外源信息。GameOver 后外部开始新局。每步同时核对完整原始帧、Lock 事件和独立诊断 trace。

这仍是开发者冻结验证，不是独立盲测。上述步数没有去重，不能作为“不同未见 G 的数量”。世界是仓库定义的简化 10×20 游戏，旋转使用可见包围框规则；本报告不外推到官方 SRS。

## 4. 因果与工程对照

| 对照 | 完整帧与 Lock 一致数 |
|---|---:|
| 正常场、同一操作流 | 3,961 / 3,961 |
| 概率场清零 | 0 / 100 |
| 输入操作通道移位 | 0 / 100 |
| 初始 trace 清零 | 1 / 101 |

三个消融流每局首次不一致即停止，故分母不同；不能拿这些分母计算与正常流等长的错误率。它们证明当前准确结果依赖概率场、操作以及 trace，不能证明 trace 角色已经自主诞生。

所有正式评估结束后，整个 `SharedField` 与评估前逐字节相同。最终 FNV 审计值 `7f8c891c6fea5713`；原生快照 SHA-256 为 `fa004a5b56c693fd630052fc9cdf228f78be13e386f51481b0d3793da7c77c2f`。快照 18,440 字节，包含固定容量、索引与 C 布局，不是 369 个条目的最小序列化格式。

严格 `C11 -Wall -Wextra -Werror -pedantic` 编译通过。O2/O3 在同一冻结场上的 23,762 步、2,000 个消行和 500 个不消行用例输出相同，仅去掉 CPU 时间字段后比较。UBSan 小规模检查通过，标准错误为零字节。

源码直接调用可达性审计从 `sf_binary_step` 出发，没有到达真实游戏函数、外部玩家评分/搜索或信用写入函数。它是简单的源码检查，不是形式化证明；冻结场与结果自回馈测试提供运行证据。

## 5. 还不能叫 Pure BPC 的原因

1. `PT_ROUTE / PT_FEAS / PT_DESTSTATE / PT_ADDRREL / PT_EFFECT` 等关系类型仍由程序预设，三种相对竖直地址以及死亡/单位向下出生效果的解释仍在。
2. 固定活动/持久分组、trace 的角色、Preview 区域和 GameOver 像素位置仍由接口解释。训练观察器通过仿真器 `State` 取得这些分组，没有证明仅从未经解释的原始像素能自生同样结构。
3. 几何、兼容、route/life、spawn、closure 的执行串接，以及分阶段课程、信用规则和重置仍有任务安排。共享参数库不等于共享生成机制。
4. 几何仍依赖最小地址锚点、预设局部方向对、一跳尺度和宏位移的单位化；旋转能力保住了，但这些也必须接受后续删除试验。
5. 外部 `lp_choose / lp_score` 含继承的游戏搜索和人工评分，只负责生成真实经验与测试操作。它们不进入 BPC 推理，不构成“BPC 学会自主玩游戏”。若整个实验也要求无外部启发式，应替换经验采样后重新证明消行覆盖。

因此，下一道核心问题是把**角色与关系类型的生成**也交给概率场，而不是继续给已有语义模块改名。本轮已经删掉并验证的内容成立，但不能把剩余架构解释成已经没有手脚架。

## 6. 复现与来源

`sh reproduce.sh` 从 C 训练并运行正式检查；`sh reproduce_negative.sh` 复现失败和同场修复。正式候选的依赖只有本目录的三个 C 文件。冻结快照采用本实验 Linux/GCC 的原生结构布局，换 ABI 应重新训练。

基线源码：`tetris/research-2026-10-05/binary-worldfit-v0.39-v0.40b/v0.40b_visible_compat_responsibility.c`。之前 v0.41–v0.43 的单边几何/局部相位删除负例仍在原研究档案，不被本实验覆盖。`evidence/isolated_*.txt` 保留两个单独删除的八种子检查；它们没有后来的反例修复，不可取代最终验证。
