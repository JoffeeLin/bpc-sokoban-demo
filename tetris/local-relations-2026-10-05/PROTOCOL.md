# Frozen deletion protocol — 2026-10-05

Baseline: GitHub commit `7025e147cd0aaf8423d6d5f7f4d1889f5765e08a`, promoted v0.40b.

Freeze the learned field before validation. No evaluation write is permitted.
The final candidate replaces the tiny-shape geometry curriculum and global
basis/phase observer with ordinary-play local pair co-occurrence probabilities,
then combines this with continuously participating downstream relaxation.

Required before promotion:

- The original eight world seeds: 1,000 episodes per seed, horizon 120,
  every frame/event and diagnostic trace exact. Expected original count 312,839.
- 2,500 cases each for clearing 1, 2, 3 and 4 rows; 2,500 vertical non-clear
  controls, all exact.
- Additional 10,000 arbitrary-address/gapped row-clear validation frames, all exact.
- Four final reserved world seeds (indices 16–19), chosen before running them:
  1,000 episodes each, horizon 120, all exact.
- Five new reserved external-player streams, seeds 20261020–20261024, 1,000 pieces
  each. Every operation exact; actual line clears must occur. External search
  and heuristic state are never supplied to the model.
- Field-off, shifted action and trace-off must worsen prediction under the
  same independently selected operation stream. Full-field bytes must remain
  identical before/after each evaluation.
- Strict GCC C11 compilation, an O3/O2 prediction comparison, and an undefined
  behavior sanitizer smoke run.

Only initial visible episode input and a newly random visible Preview after a
successful real Lock may be injected. Never replace the predicted board with
the true next board. Every subsequent tick uses the model's own prediction.

This is a developer-frozen validation inside a supplied simplified 10×20
world. It does not validate arbitrary official Tetris, an independently blind
test, fully self-born cognitive structure or autonomous BPC play.

## Counterexample after the first freeze

The earlier candidate and the old v0.40b baseline both diverged at piece index
252/action index 4 of seed 20261010. Non-contiguous three-row closure exposed
probability-scaled displacement: an intermediate row shifted one cell instead
of two, formed a spurious full row, and triggered an extra relaxation.
Preserve that negative evidence. The new propagator carries displacement and
conditional amplitude separately and is shared by execution and counterfactual
credit. World indices 8–15 and seeds 20261010–20261019 are now development/regression data; only the
new reserved streams above serve as the subsequent fresh autoplay validation.

## Final bootstrap deletion, before re-freezing

The initial Spawn/GameOver synthetic preview/obstacle curriculum was replaced
with 2,500 actual Down/Lock observations. The training auxiliary microstep now
also evaluates downstream relations continuously. Freeze after retraining, then
validate newly reserved world indices 16–19 and player seeds 20261020–20261024.
Previous validation is regression evidence after this change.
