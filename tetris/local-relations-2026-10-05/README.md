# BPC Tetris：局部关系拟合与手脚架删除

本实验继续删除 v0.40b 的几何与调度手脚架。几何改为从真实游戏变化中统计局部邻接方向对，在共享概率场中叠加，再通过同步空间松弛生成结果；下游关系持续参与每个推理微步。还删除了人工 Spawn 棋盘训练，并修复基线共有的非连续三行消除反例。

这是**已验证的删除候选，尚非最终 Pure BPC**。固定关系词表、trace 角色解释、模块串接、单元位移效果和分阶段训练仍在。外部玩家用于产生经验与验证轨迹，BPC 负责拟合世界变化，尚未由 BPC 自主选择玩法。

| 冻结验证 | 结果 |
|---|---:|
| 原八组世界连续预测 | 312,839 / 312,839 |
| 新保留四组世界连续预测 | 155,842 / 155,842 |
| 连续底部消行 / 任意位置消行 | 10,000 / 10,000；10,000 / 10,000 |
| 竖直满列不消行 | 2,500 / 2,500 |
| 新保留外部玩家轨迹 | 5,000 块，22,025 / 22,025 次操作 |

每次评估的概率场均逐字节不变。全部源码、编译与训练使用 C；验证棋盘只用于测试，没有进入训练。
