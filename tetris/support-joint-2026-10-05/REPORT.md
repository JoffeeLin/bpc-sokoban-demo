# 删除固定支持优先级：实验结果与边界

## 结论

候选在推理中删除了全局支持优先、最大局部支持优先和命中后停止。
统一概率残余保住两段各 226 步的历史闭环，但在完整经验后的连续
预测明显退步。直接平均也失败。**本轮拒绝晋级，继续保留 373 耦合
有效基线。** 这否定的是这次具体实现，不是否定 BPC 理论。

## 唯一主要改动

原模型从一个支持读 Beta 概率；候选查询全部物理支持的有符号残余：

`p = sigmoid(sum(r)/sqrt(5))`

真实下一像素到达后，`e = y-p`，每个实际可写支持收到
`r += 0.5*e/sqrt(5)`。每个独立模型只有一个扁平场；MODE 在编译时
选择版本，不在运行时按任务选择算法。三个版本分别是原优先级查表、
全部已知概率的等权平均、联合概率残余。

方程对应底层定义中的 BPC-0；数学上是稀疏、加性 logistic 概率估计，
不能靠“波场”名称主张它已经具有新的函数表达能力。没有引入网络层、
神经网络库、对象标签、语义拆解、候选评分或任务策略。

物理坐标、0/1/2 半径、三帧、六路对称 XOR 历史、真实外部预览输入、
手写操作带、硬错误触发整场支持出生全部保持。原位置共享诊断已经
表明存储压缩与连续泛化并不自动一致，所以本轮没有同时修改寻址。

三个版本都使用 32 字节单元、1,000 万条目的容量上限。候选的预测会
影响后续支持出生，所以学习出的地址集合略有差异；这不是相同地址
集合的读出比较，而是同经验、同最大物理预算的完整学习对照。容量
上限均未触及。`audit.c`、`environment.h` 与父版逐字节相同。

## 小规模与历史对照

三个训练种子 55941–55943，各训练 2,000 个真实方块，再训练原历史
对照。新开发者留出流 20261111–20261113，各 100 回合、最长 120 步。
同一测试流分别用于三个独立训练场，所以以下是三个模型的汇总，
不是 900 个不同环境流。测试期间不学习。

| 读出 | 正确自预测前缀步 / 检查步 | 无错回合 |
|---|---:|---:|
| 原优先级 | 862 / 1,762 | 0 / 900 |
| 等权概率平均 | 393 / 1,293 | 0 / 900 |
| 联合概率残余 | 63 / 963 | 0 / 900 |

另外，各版本用原两条实际历史单独冷启动训练 100 次，训练等待 6 次
无效操作，冻结验证等待 200 次。三个有历史版本都保持 2/2 末步探测
和两段各 226 步的完整自滚动；无历史版本均只有一段闭合。交换历史
后均为 0/2，清空后为 1/2。这是已训练作用在更长等待中的因果保持，
不能据此声称已经获得新形状、新场景泛化。

三个独立有历史模型训练同一实际游戏流：seed 55901，20,000 个方块、
100,121 次实际操作，再加 6,400 次历史对照操作。匿名端口暴露为
20,030 / 18,323 / 14,573 / 27,963 / 19,232。没有合成训练棋盘，也没有
根据画面挑选动作的策略。原查表计数摘要 `0a83771b788619b0` 与父版
完全一致，确认参考模型行为没有意外变化。

|---|---:|---:|---:|
| 原优先级 | 8,191,860 | 15,455 / 27,455 | 0 / 12,000 |
| 等权概率平均 | 8,231,890 | 9,232 / 21,232 | 0 / 12,000 |
| 联合概率残余 | 8,227,594 | 6,693 / 18,693 | 0 / 12,000 |

原八个世界流和新索引 28–31，各 1,000 回合、最长 120 步。各版本的

## 原始差异与因果诊断

相同的 100 个真实回合共 3,856 步，实际改变 21,360 个像素位。诊断
只比较原始像素差异，不给模型提供“活动块、锁定”等类别。

| 读出 | 完整画面正确 | 改变位预测错误 | 未改变位预测错误 |
|---|---:|---:|---:|
| 原优先级 | 189 / 3,856 | 11,972 | 6,634 |
| 等权概率平均 | 147 / 3,856 | 13,810 | 5,613 |
| 联合概率残余 | 121 / 3,856 | 13,245 | 6,761 |

下降尤其出现在端口 2、4：联合残余分别为 2/793、0/1,159 帧，原版为
41/793、13/1,159。这里仍只是外部匿名端口统计，不能直接推出某个
残余已经形成命名函数。错误同时涉及变化预测与当前身份保持。

完整联合场的末步历史探测为 2/2，清空或交换历史降为 0/2。另一个
100 回合冻结样本中，正常残余正确前缀为 43 步，全部残余反相或在
物理地址间循环错位后均为 0。各干预后检查场保持冻结并恢复原字节。
这证明残余方向、地址与历史确有作用；仍不能把作用性等同于有用泛化。

## 工程验证与可复现性

严格 C11 / Werror 通过。联合场的完整 O2 / O3 训练输出逐字节相同：

`d360e010551f8ceaaa5ac75619143ff61ca0c6f043d9e8c170d61151c79a3a02`

两段历史、100 回合预测与 1,000 方块自滚动的 O2 / O3 / UBSan 输出
一致，UBSan 标准错误为空。全部冻结检查包含残余的完整场内存字节
哈希；计数摘要本身不包含残余，不能替代冻结检查。

原始日志在 `evidence/`，协议在首次运行前冻结。没有针对留出失败
调整学习率、语料或地址。完整失败场不提交仓库，原生文件大小与
SHA-256 在 `SUMMARY.json`，可由 C 程序重建。条目数只是结构成本
代理，不能直接声称已经测得理论中的不可约 K。

## 后续判断

本轮不支持“取消优先级后直接平均或加性叠加，便得到可组合函数”。
它只完成了一次可复现的删减尝试。固定窗口、完整条件哈希、整屏缓存、
人工历史组织仍在；候选没有实现自生过程状态或长距离函数传播。
下一问题应是：原始条件如何在传播中保持身份，并使远处真实作用
形成可复用局部耦合。需要独立的小 C 实验，不能用这次失败的留出流
逐题补丁，也不能重新加入游戏角色与阶段执行器来宣布纯净成功。
