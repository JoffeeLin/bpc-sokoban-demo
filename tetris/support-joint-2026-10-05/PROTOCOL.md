# Support priority deletion — frozen experiment protocol

Baseline: `cabf09884d1a8f65645e4feefaa473e5412b06c3`, raw-history model.
The successful 373-coupling model remains the game benchmark.
This candidate changes probability readout and residual teaching only. It
retains physical addresses, radii, three frames, six symmetric XOR ports,
real-action tapes and residual-triggered whole-medium support birth.

Three separately compiled, independent one-field models:

0. Original global-first / largest-known-local-support priority, Beta counts.
1. Equal mean of all known Beta probabilities, a pooling control.
2. All physical supports participate in `p = sigmoid(sum(r)/sqrt(5))`;
   real `e = y-p` writes `r += 0.5*e/sqrt(5)` to each existing/new participating
   support. No top-1, confidence ranking, task labels or neural-network library.
   These equations are BPC-0's sparse residual readout and are mathematically
   additive logistic estimation, not a claimed novel function family.

All models have the same 32-byte cells and 10,000,000-cell upper bound. Counts
remain in the residual model for matching bookkeeping; only residuals predict.
Birth decisions depend on each model's own predicted bit, so inventories may
differ as a causal consequence. This is equal maximum budget, not identical
learned keys. Whole-medium birth still uses the retained hard-error rule.
Observation writes are sequential per physical pixel, as in the original.

Frozen before the first candidate execution:

- Pilot: memory on, each of seeds 55941–55943, 2,000 real pieces plus the
  original two executed histories repeated 100 times. New developer-held-out
  seeds 20261111–20261113, each 100 episodes, horizon 120. Teacher forcing is
  diagnostic only. Primary measure: exact self-predicted prefix and whole
  error-free episodes. Same actual trajectories across variants.
- History check: independent cold fields trained on the original pair only;
  6 no-ops in training, 200 in testing. Keep whole 226-step trajectories and
  erase/swap/action-offset controls. Two probes alone do not establish closure.
- Full: memory on, seed 55901, 20,000 real pieces plus pair training. This
  seed preserves comparison with archived raw-history counts. Old world
  indices 0–7 and newly reserved 28–31, 1,000 episodes per stream, horizon 120.
  Five new action streams 20261121–20261125, 10,000 pieces each, no truth
  replacement of the board. Real initial frame and external preview inputs
  remain the established interface.
- If pilot joint readout is clearly worse, retain that negative result and
  do not tune against these held-out streams. At least one full joint vs
  reference comparison is required to separate small-exposure failure.
- Probability field byte hash must remain unchanged throughout every test.
  Require strict C11/Werror, O2/O3 output agreement and UBSan smoke. Existing
  373-coupling baseline must remain unchanged and be rerun on new indices.

Promotion requires greater unseen continuous prediction with history evidence
preserved, acceptable structure cost and stable implementation. A prefix
increment is partial evidence only. Zero whole-game closures cannot be called
Pure BPC game success. Frozen windows, hash conditions and global cache remain
open scaffolds even if this one deletion improves results.

Physical data come only from actual execution of the previously handwritten
operation tapes. No generated teaching boards, semantic annotations, policy
score, target-directed tape selection or self-generated teacher feedback.

Equation references: uploaded BPC bottom definition V2.7 §§6 and 11; mathematical
check https://cs229.stanford.edu/notes2019fall/cs229-notes1.pdf (logistic likelihood
and online update). These references do not establish game generalization.
