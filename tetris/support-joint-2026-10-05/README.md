# BPC Tetris：删除固定支持优先级的对照实验

**结论：候选没有通过验收，继续保留 373 耦合有效基线。**

本轮比较原优先级查表、支持概率直接平均、同场联合概率残余。
联合残余候选删除了推理中“命中全局或最大局部支持就停止”的分支。
它保住两段历史的 452 步连续闭环，但完整经验后的未见连续预测退步。
这不是已经完成的 Pure BPC 游戏，也不证明 BPC 理论无效。

Linux / x86-64，仓库根目录执行：

```sh
bash tetris/support-joint-2026-10-05/reproduce.sh quick
bash tetris/support-joint-2026-10-05/reproduce.sh full
```

每个独立模型只有一个概率场。MODE 只在编译时选择实验版本；运行时
不按任务选路。完整模型约 262–263 MB，属于被拒绝的中间模型，不纳入
仓库；C 源码、手写操作带、种子、原始日志与 SHA-256 足够确定性重建。
full 串行执行以控制内存，单模型训练峰值约 0.8 GiB。

验证脚本通过表示重现了这次拒绝结论，**不表示游戏拟合通过**。
