# 删除预设身份：原始画面与通用历史实验

**状态：对照历史通过，完整游戏失败，不替换上一版。**

这是 `direction-axis-2026-10-05` 之后的一次独立冷启动实验。核心不再
读取活动块、固定棋盘、trace、形状、消行阶段或目标评分，只读取原始
像素、匿名操作地址和统一物理历史。删除预设身份不等于删除历史。

两条真实执行的历史在 200 次相同无效移动后具有完全相同的画面和
最近三帧，但下一次同样的右移产生不同结果。统一历史记忆使这两条
各 226 步的自滚动全部正确；仅靠短画面窗口无法同时正确。

完整游戏没有通过：有记忆候选在 12,000 个冻结测试回合中均出现错误；
五条新操作流的 250,434 步中只有 16,450 步完整画面正确。因此这不是
已经完成的 Pure BPC 俄罗斯方块。

在 Linux / x86-64 上，仓库根目录执行：

```sh
bash tetris/raw-history-2026-10-05/reproduce.sh quick
bash tetris/raw-history-2026-10-05/reproduce.sh full
```

`quick` 重现同画面反例、局部视野失败和无身份记忆对照，比较 O2 / O3 /
UBSan。`full` 另外重新训练两个独立概率场，重现完整游戏的拒绝结果。
验证脚本成功表示重现了报告，**不表示完整游戏拟合通过**。

两个小型对照场保存在 `pair_memory.bin` / `pair_raw.bin`。完整候选场分别
约 197 MB / 77 MB，属于被拒绝的中间模型，不加入仓库；源代码、手写
操作带、种子、全部结果和 SHA-256 足够确定性重建，O2 / O3 已逐字节
验证一致。每个运行中的模型始终只有一个概率场。
