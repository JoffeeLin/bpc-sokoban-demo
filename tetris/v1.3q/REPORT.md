# BPC Tetris v1.3q — 匿名区域关系自生实验

日期：2026-10-04

## 1. 问题

v1.2 已证明层级残余可以把成熟一步重力函数、局部残余和跨区域关系组合起来：人工指定一个可见 16-bit 远程区域时，seed0 在 20k+20k 训练点达到 terminal full 58.17%、递归到真实 Lock/Spawn 后 full 24.33%。但 v1.2 的 F2 仍由研究者指定了远程区域，因此还不能称为“关系区域自生”。

v1.3 的目标只有一个：

> 删除“研究者知道远程可见区域在哪里”这个脚手架，让所有可见 16-bit 区域匿名、同权地成为候选，并只靠独立现实残余决定哪些跨区域关系成熟。

模型内部没有 `Preview`、`Lock`、`Spawn`、`piece_type`、`landing_y`、planner、search、top-k 或任务评分。

## 2. 失败分支与定位

### v1.3a–f：共享候选场 / 连续 gate

把 416 个可见 bit 均匀分成 26 个匿名 16-bit 区域后，让所有区域共享一张高容量候选关系表。结果候选之间通过共享地址互相泄漏，或低置信 gate 被归一化放大；普通下落被污染，terminal full 长期保持 0%。

结论：**候选身份必须在出生阶段保持独立，否则真实有用关系的残余会污染其他候选。**

### 独立区域外部审计（不喂给模型）

对 26 个匿名区域逐个使用完全相同的 v1.2 关系容量训练并冻结测试。区域 25 明显表现出更强的可复用未来作用：

- terminal full：18.00%
- terminal active：74.67%
- terminal preview：97.67%

其他区域的 preview 多数为 0–26%。说明原始可见画面中确实存在可被自动发现的高价值远程关系源，不是所有区域信息等价。

进一步把关系使用的源区域值替换成另一个匿名区域，区域 25 的结果从：

- full 19.33% → 0.00%
- active 77.00% → 0.33%
- preview 97.33% → 0.00%

说明其作用真实依赖该源信息，而不是只借用了局部上下文。

## 3. v1.3q 机制

### F0：成熟局部一步重力函数

继续使用纯局部 Beta 残余介质，只学习真实一步重力转移。

### F1：局部残余

F0 无法解释的局部残余进入 translation-equivariant 局部关系场。

### F2：匿名区域候选生命周期

将 416 个可见 bit 均匀划分为 26 个物理 16-bit 区域。每个 source block 拥有隔离的 v1.2-style 稀疏候选关系场，不与其他候选共享权重。

候选先在一批现实经历中学习；随后冻结，在完全独立经历上验证。对于每个匿名 output block：

1. 如果 F0+F1 已经把该 16-bit block 完整预测正确，不产生 F2 成熟信用；
2. 只有 F0+F1 失败时，才观察候选是否把整个 16-bit block 完整恢复正确；
3. 成功/失败形成 Beta 概率；
4. 独立残余事件不少于 64，且后验正确概率 ≥ 0.80 时，关系成熟；
5. 所有成熟关系同时连续参与，不做 top-k、winner、人工区域选择。

成熟后的参与幅度直接等于其独立验证概率，不再把弱概率重新归一化成满强度。

## 4. 3-seed 冻结正式结果

训练参数：

- F0：15,000 一步重力经历
- F1：20,000 混合 fall/terminal 残余经历
- 每个匿名 F2 候选：5,000 训练经历
- 每个候选：1,500 独立验证经历
- 冻结评估：400

### 自生结构

三个 seed 均只留下 3 条成熟强关系，并全部来自同一个匿名 source block 25：

- seed0：`25→12 q=0.96`，`25→13 q=0.99`，`25→25 q=0.97`
- seed1：`25→12 q=0.94`，`25→13 q=0.97`，`25→25 q=0.97`
- seed2：`25→12 q=0.95`，`25→13 q=0.98`，`25→25 q=0.98`

程序从未把 25 命名为 Preview，也没有把 12/13/25 命名为某个游戏阶段；这些编号只是均匀物理分块坐标。

### 平均能力

| 指标 | 3-seed 平均 |
|---|---:|
| 普通下落 full | **78.67%** |
| 普通下落 board | 84.17% |
| 普通下落 active | 83.00% |
| Terminal full | **50.17%** |
| Terminal board | 57.50% |
| Terminal active | **75.67%** |
| Terminal preview | **97.92%** |
| 递归最终 full | **17.92%** |
| 递归最终 board | 32.17% |
| 递归最终 active | 31.83% |
| 递归最终 preview | 70.92% |

### 因果消融

三个 seed：

- `relOff`：terminal full **0%**；recursive full **0%**
- `relFlip`：terminal full **0%**
- `relShift`：terminal full **0%**

因此 terminal 闭合不是 F0/F1 单独产生，也不是成熟关系的惰性旁路。

## 5. 与 v1.2 的关系

v1.2 seed0 在人工指定远程区域、20k+20k 点：

- terminal full 58.17%
- recursive full 24.33%

v1.3q 删除人工区域后，3-seed 平均仍保留：

- terminal full 50.17%
- recursive full 17.92%

所以本轮不是能力提升，而是**删除认知脚手架后仍保留大部分能力**。这比继续把 58% 往上堆更重要。

## 6. 证据边界

本轮允许写成：

> 在当前受控 Tetris 世界中，均匀匿名物理区域可以通过“候选隔离 → 独立现实验证 → 残余块完整恢复概率 → 成熟/死亡”的任务无关生命周期，自行形成少量跨区域关系；这些关系对 terminal 阶段闭合具有直接因果作用，并在 3 个独立 seed 上复现。

本轮不能写成：

- BPC 已经理解 Preview / Lock / Spawn；
- 匿名区域划分本身已经自生（16-bit 分块仍是工程介质）；
- Line Clear / Game Over 已解决；
- 已拟合完整俄罗斯方块；
- 已证明通用 AGI 结构出生。

## 7. 下一步

下一步不应继续提高 F2 训练量，而应删除最后一个明显脚手架：**固定 16-bit 区域边界**。

建议 v1.4：让原始画面中的关系支持域由残余自行 split/merge；只要两个相邻物理区域长期具有相同未来作用，就允许合并；同一支持域内部出现不可解释残余时允许分裂。验证是否仍能自行恢复当前三条远程关系，并继续保持 terminal full 非零。
