# BPC × 俄罗斯方块 v1.2：层级残余闭合实验

日期：2026-10-03

## 1. 研究问题

此前 v0.4.1 的完整俄罗斯方块世界模型能够较好拟合局部移动，但 Hard Drop / Lock / Clear / Game Over 的完整帧仍为 0%。本轮只攻击一个问题：

> 已经成熟的局部一步函数，能否在现实残余持续出现时形成新的局部关系和跨区域组合关系，并最终闭合到未直接训练的长程阶段结果？

BPC 内部仍不接收 `piece_type / x / y / rotation / landing_y / collision / lock / clear / spawn` 等字段。

## 2. 首先修正了两个实验判断

### 2.1 纯重力递归其实已经可以成立

v0.8 使用 GitHub pure-BPC 风格的局部 Beta 残余介质，只训练真实的一格非锁定下落。3 个 seed、30k 经验，冻结后：

- h=1,2,3,5,8,12,16 的完整画面均为 **100%**；
- 因此“BPC 不会重复调用一步函数”这一判断被否定。

真正失败的是：把“继续下落”和“碰撞后的阶段转换”放进同一个介质以后，关系发生干扰。

### 2.2 v0.8 terminal 实验曾存在信息闭包缺口

简化版 v0.8 只输入棋盘+活动块，删掉了用户肉眼可见的 Next Preview。碰撞后新活动块的身份依赖 Preview，因此 spawned active=0% 不能全部归因于过程状态失败。

恢复完整可见输入后，简单全局关系波仍不能让 terminal 完整闭合，说明信息闭包不是唯一问题。

## 3. 单层非局部关系的能力边界

用完整可见画面形成匿名波到波关系场，在 terminal-only 课程中：

- 5k：spawned active exact = **21.75%**
- 10k：**25.75%**
- 20k：**22.75%**

出现明显平台。清零关系波后为 0%，说明非局部关系确有因果作用，但一个单层全局关系仍不足以闭合。

## 4. 关系×关系：第一次跨距离阶段关系

v1.1 不再让一个局部片段直接决定整个未来，而让：

`局部 3×3 原始现实片段 × 另一块原始可见 16-bit 片段 -> 残余关系`

模型仍不知道这些片段代表什么。

5k 关系经验后，terminal：

- active exact = **98.75%**
- preview exact = **98.75%**
- 去掉、反相或错位组合关系后重新接近 0

这首次证明：两个原始现实片段的组合能够形成远距离阶段关系。

但 locked board 仍为 0，说明不同几何作用不应全部压成同一种全局关系。

## 5. v1.2：层级残余

因此 v1.2 冻结为三层：

1. **F0：成熟局部重力函数**  
   只从普通一步重力经验形成，之后冻结。
2. **F1：局部残余关系**  
   F0 解释不了的残余，按匿名 3×3 / 5×5 支持域写回当前局部坐标。
3. **F2：跨区域组合关系**  
   F1 之后仍解释不了的残余，进入 `局部片段 × 第二原始可见片段` 的关系记忆。

没有任何 `if(lock)`、`spawn()`、Hard Drop 规则写入模型。

## 6. 三 seed 正式结果（每层残余 5k）

| seed | Fall full | Terminal full | Recursive-to-lock full |
|---:|---:|---:|---:|
| 0 | 76.00% | **29.50%** | **13.25%** |
| 1 | 75.00% | **30.75%** | **9.75%** |
| 2 | 74.25% | **29.50%** | **10.25%** |
| 平均 | **75.08%** | **29.92%** | **11.08%** |

Terminal 分组件三 seed 平均：

- locked board exact：**33.25%**
- spawned active exact：**79.83%**
- preview exact：**98.75%**

关键消融：

- Pair relation OFF：terminal full = **0/3 seeds**
- Pair relation OFF：recursive full = **0/3 seeds**
- Pair relation flip / address shift：terminal full 同样为 0
- Local residual OFF：terminal full 同样为 0

因此完整闭合要求两层残余同时存在。

## 7. 学习曲线仍在增长

相同 seed0：

| F1/F2 经验 | Fall full | Terminal full | Recursive full |
|---:|---:|---:|---:|
| 5k / 5k | 76.00% | **29.50%** | **13.25%** |
| 10k / 10k | 77.50% | **47.00%** | **16.50%** |
| 20k / 20k | 83.83% | **58.17%** | **24.33%** |

所以当前还没有看到 terminal 能力饱和。

## 8. 未知长度递归闭合

20k/20k 的 seed0 冻结后，按真实锁定距离分组。模型不知道落距，只不断把自身预测重新输入直到相同步数，比较最终真实状态。

- h=1~7：full 约 **26.8%~33.3%**
- h=8~18：多数仍约 **17.7%~30.0%**
- Pair relation OFF：**每一个 h 都是 0% full**
- h=19~20 样本太少，不作结论

此前已经用独立审计证明：在当前简化 Tetris 环境中，连续 `ACT_NONE` 到首次锁定与一次 `ACT_DROP` 的最终真实画面 100% 等价。因此这里的 recursive full 可以视为：

> **从未训练 ACT_DROP 目标，只靠已学一步世界函数与残余层级，恢复 Hard-Drop-equivalent 最终状态。**

20k/20k 时该完整闭合为 **24.33%**。

## 9. 这轮真正说明了什么

本轮最强证据不是“俄罗斯方块已经拟合完成”，而是：

`局部一步函数 -> 局部未解释残余 -> 跨区域关系组合 -> 未知长度重复 -> 阶段终态`

第一次形成了非零、可复现、可消融的闭环。

它解释了此前推箱子与俄罗斯方块的差异：Sokoban 大量单步规律在局部物理支持范围内即可闭合；Tetris 的 Lock/Spawn 需要把不同空间尺度的关系继续组合。

## 10. 仍然没有解决

1. **Line Clear 未单独通过严格冻结测试。**
2. Game Over 未单独通过。
3. 普通随机全动作 Tetris 世界尚未达到高完整帧率。
4. 当前 F1 的 3×3/5×5 支持范围仍由研究者给出。
5. 当前 F2 明确使用了一个固定的第二 16-bit 可见区域；虽然它只是原始画面而非 `piece_type` 标签，但仍属于实验脚手架。
6. 课程先让 F0 成熟、再写 F1/F2，也是外部课程安排；尚未证明层级生命周期完全自生。

因此 v1.2 是**机制正证据**，不是“纯净 BPC 已经完整学会俄罗斯方块”。

## 11. 下一步

最值得做的 v1.3 不是继续加训练量，而是删除第 5 条脚手架：

- 把完整画面切成许多**匿名固定物理块**；
- 不告诉 BPC 哪一块是 Preview；
- 现实残余自己决定“哪个局部片段应该与哪个另一片段形成组合关系”；
- 保持固定容量，做 birth / reuse / death；
- 若仍能维持 terminal 与 recursive 增益，才说明跨区域函数开始真正从画面中自生。

随后才进入 Line Clear。
