# Current-carrier binding — frozen C experiment protocol

Source baseline: `b63bea76b2575ff90f165ca27ee247f76e42730e`,
`tetris/support-joint-2026-10-05`. No previous source or field is overwritten.
The successful 373-coupling game benchmark remains intact.

The prior all-support probability field failed unseen continuous prediction.
The uploaded BPC group-relation proposal motivates learning physical changes
and applying them to a raw carrier. However, merely recoding the target as
`delta = current XOR real_next` is algebraically equivalent when every
participating key already contains the target current bit. This is an
equivalence control, not an alleged new binding mechanism.

Four independent MODE=2 fields form a 2x2 experiment:

| ID | Learned target | Target current bit in local keys | Readout |
|---|---|---|---|
| next | next raw bit | present | predicted next bit |
| delta | XOR change | present | current XOR predicted change |
| split_next | next raw bit | omitted | predicted next bit |
| split_delta | XOR change | omitted | current XOR predicted change |

`split_delta` is the candidate. It removes just the lowest/current bit of the
target site's code from every local radius, uniformly for all pixels and
ports. The physical raw state is not erased: it remains in the carrier and
participates in reconstruction every tick. Previous frames, symmetric port
traces and the inherited whole-medium conditional cache still contain raw
identity. Thus this does not claim complete identity factorization, learned
support discovery or a dynamically propagated function. `split_next` isolates
query omission from relational reconstruction. An independent MODE=0 original
priority model is also evaluated as a historical reference, not as candidate
runtime selection.

Every field uses the same 32-byte cell type, 10,000,000-cell maximum, ETA=0.5,
four fixed local supports plus one optional global support, and no internal
ranking in MODE=2. The delta field learns only actual observed XOR changes;
global birth compares reconstructed raw predictions with actual raw results.
Ties/unseen reads preserve the current bit in both encodings. Inventory may
differ through error-triggered global births; equal upper bound does not mean
identical learned keys. Logistic residual equations remain unchanged.

Frozen before the first candidate execution:

- Pilot: the four MODE=2 variants, each trained on 2,000 real pieces with
  seeds 55961–55963, then the same two actually executed histories repeated
  100 times. Test streams 20261141–20261143, 100 episodes each, horizon 120.
  Record self-prefix/whole episodes, truth-fed diagnostics and a fingerprint
  of all truth-fed raw predictions. Compare intact-key next/delta equality.
- History: cold independent fields trained only on the old pair. Six no-ops
  in teaching, 200 in testing. Require raw-history alias, both 226-step
  self-rollouts, and erase/swap/next-port-offset diagnostics. No guarantee is
  assumed in advance; failures are recorded.
- Full: `split_next` and `split_delta`, each 20,000 real pieces, seed 55901,
  plus the identical pair replay. Existing compatible `next` and original
  priority fields from the baseline may be reused, verified by SHA256.
  New world indices 32–35, 1,000 episodes each, horizon 120. The same actual
  worlds continue after model failure so RNG and world trajectories agree.
  Truth-fed runs use 100 episodes per index, solely as diagnostics.
  Five new continuous tape streams 20261151–20261155, 10,000 pieces each.
  Initial raw frame and external preview input retain the established audit
  interface; the board is never replaced with truth during self-prediction.
- A poor pilot is retained without tuning. Both split arms receive the full
  exposure to distinguish small-data failure. No parameter or support changes
  after inspecting any of these test streams.
- Post-failure diagnostics: 100 truth-fed worlds, seed 4898939; per-port raw
  changed/unchanged bit errors. Residual phase reversal and address rotation:
  100 self-predicted worlds, seed 20261161, then exact byte restoration.
  Existing history/operation-offset controls are retained unchanged.
- Implementation: strict C11/Werror, frozen full-table byte hashes in every
  validation, candidate O2/O3 full-field byte agreement, UBSan smoke, reject
  mismatched native target/query headers. Rerun the unchanged 373-coupling
  benchmark on indices 32–35.

Acceptance requires greater unseen continuous self-prediction while retaining
history effects and not inflating structural cost proportionally. A prefix
gain or static-pixel accuracy alone is partial evidence. Zero error-free
episodes is not Pure BPC game closure. Occupied cell counts/bytes are storage
proxies, not a measured irreducible theoretical K. Fixed radii, three frames,
XOR history, conditional hashes/cache and external reset/preview timing remain
open assumptions, regardless of this candidate's outcome.

Only old handwritten operation tapes and actual environment executions teach
the field. No generated teaching boards, semantic annotations, scoring policy,
task-directed tape choices, or model-generated teacher targets are added.

Theory reading: uploaded voxel-function text section 3.8 (XOR group relation),
function-compression text section 11 (preserve identities and test causal
binding). The latter also warns that changing aggregate targets alone does
not establish correctly directed behavior. This test is a limited physical
carrier experiment, not a claim that language/variable binding is solved.
