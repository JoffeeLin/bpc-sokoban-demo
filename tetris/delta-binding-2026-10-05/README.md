# BPC Tetris：当前载体与变化关系的 C 实验

**结论：完整经验后退步，本轮候选不采用，保留有效游戏基线。**

本轮检验把当前原始像素作为载体、让同一概率场学习实际变化。
首先发现“去掉当前位”仍可由端口 XOR 历史还原，是等价改写。
随后用全新留出流测试移除目标位置整组局部编码的候选。小实验有
前缀收益，2 万块经验后收益反转：4,000 个未见回合的正确前缀从
2,320 步降至 1,083 步，完整无误回合仍为 0。

Linux/x86-64，在仓库根目录运行：

```sh
bash tetris/delta-binding-2026-10-05/reproduce.sh quick
bash tetris/delta-binding-2026-10-05/reproduce.sh full
```

各编译版本是独立实验模型，各自仅一个概率场，运行时不选择模型。
教学仍是原有手写操作带在真实环境中的执行结果。核心没有新增游戏
角色、评分、物体类型或神经网络库；原有固定支持与全局条件缓存仍在。

验证通过表示重现了这次失败和保存了有效基线，不表示纯净 BPC
完成游戏闭环。全量字段约 260–299 MB，不纳入仓库；源码、日志、种子
与 SHA256 可以确定性重建。full 串行运行，单模型训练峰值约 0.8 GiB。
